# Reel

Reel 是面向视觉小说的跨平台游戏引擎，Aside 是其 Rust 实现的嵌入式语言。

当前已完成首版设计审查，进入实现准备。架构、语言和作者指南见 [docs](docs/README.md)。所有能力状态以文档标记和实际实现为准。

Reel is a cross-platform visual novel engine with Aside, an embedded language implemented in Rust.

The first design baseline has been reviewed; implementation preparation is next. See [documentation](docs/README.md) for the architecture, language specification, and bilingual creator guide.
